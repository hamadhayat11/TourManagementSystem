# Tour Management System - JavaFX Application

## 📌 Overview
A JavaFX-based desktop application for managing and booking tour packages in Dubai. The system allows users to:
- Browse available tour packages
- Select desired packages
- Enter personal details
- Generate tour tickets

## ✨ Features
- **User Authentication**: Simple login system
- **Tour Package Management**: View and select from pre-defined packages
- **Booking System**: Enter personal details and booking information
- **Ticket Generation**: Automatic ticket creation with booking details

## 🏗️ Project Structure
tourManagementSystem2/
├── Main.java - Application entry point
├── TourManagementSystem.java - Main application class with JavaFX UI
├── TourPackage.java - Tour package entity class
└── User.java - User entity and authentication logic

## 🚀 Getting Started

### Prerequisites
- Java JDK 11 or later
- JavaFX SDK (included with JDK 11+)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/tour-management-system.git
Open the project in your preferred Java IDE (IntelliJ, Eclipse, etc.)

Configure JavaFX SDK in your IDE

Run Main.java to start the application

🖥️ Usage

Package Selection:

View available tour packages
